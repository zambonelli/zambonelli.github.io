Si indicano di seguito gli strumenti software che si utilizzano durante il corso e si indica dove e' possibile reperirli.


Sistema Operativo UNIX
  • I PC del laboratorio di informatica di base si possono collegare a un sistema UNIX dal quale e' possibile esercitarsi e programmare in Bourne Shell. Rivolgersi appena possibile a Massimo Vignone (tecnico del laboratorio presso il DSI) per farsi dare lo username e la password necessarie per accedere al sistema.
  • E' possibile usare il sistema operativo LINUX, di pubblico domino, installandolo sul proprio PC.


Programmazione ad Oggetti e Java
  • Si utilizza la versione di Java 1.2. E'di pubblico domino e si puo' scaricare dal sito The Java Sun Site.
  • Molte riviste di informatica e libri su Java allegano il CD con Java 1.2 in omaggio
  • Il sistema Java e' disponibile sul sistema UNIX sopra citato.



Architettura dei Calcolatori e Assmbler
  • Si utilizza l'ambiente di programmazione integrato Turbo C della Borland, che comprende anche il compilatore Assembler. Il sistema non e' di pubblico domino. Percio', anche se e' potenzialmente molto facile copiare tale sistema per installarlo sul proprio PC a casa, il docente scoraggia l'adozione di questa pratica.
  • E'possibile, per la parte C soltanto, usare un ambiente di programmazione integrato per il C disponibile qui: Il compilatore DJGPP
