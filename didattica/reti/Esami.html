Regole d'Esame

La modalita' principale per sostenere l'esame e' realizzare un progetto software in Java che preveda l'esecuzione di un sistema software distribuito che faccia uso delle librerie Java per la programmazione di Rete. Alla discussione di tale progetto sara' contestualmente accompagnata una prova orale relativa a tutte le tematiche del corso.

Il tema del progetto dovra' essere stabilito in accordo con il docente. QUINDI, IMPORTANTE: Accordarsi preventivamente con il docente prima di iniziare il progetto!!!

E' anche possibile realizzare un progetto congiunto con l'esame di Tecnologie e Applicazioni Web, previo accordo congiunto con entrambi i docenti.

In alternativa, e' possibile svolgere l'esame in modalita' tradizionale, con un esame orale accompagnato in ogni caso da svolgimento in sede d'esame di esercizi di programmazione di rete in Java.
