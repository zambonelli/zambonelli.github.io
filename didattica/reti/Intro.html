Corso di:

RETI DI CALCOLATORI 

 

 

Docente: Prof. Franco Zambonelli

 

 

Scopo del Corso

Fornire le conoscenze culturali e metodologiche per la comprensione delle reti di calcolatori, del loro funzionamento, e della loro programmazione. Si pone particolare attenzione al concetto di Internetworking e ai protocolli Internet.

Il corso adotta una prospettiva sistemistica delle reti, in cui i calcolatori e le reti che li connettono sono parte di un sistema complesso, e come tali devono essere gestite e programmate.

A tale scopo, il corso introduce anche i concetti base della programmazione ad oggetti, necessaria per comprendere e gestire le reti, adottando il linguaggio Java come base per la comprensione e lo sviluppo di applicazioni di rete e applicazioni Internet.

Conoscenze Richieste e Propedeuticita'

Si richiedono le conoscenze fornite dai corsi base di informatica:

  • Capacita' di Definire Algoritmi

  • Programmazione di base in Linguaggio C

  • Capacita' di Uso di Sistemi Windows

 

Programma del Corso

Parte 1: (5 ore)

  • Breve introduzione ai concetti di base delle reti di telecomunicazione e di calcolatori
  • Concetti di internetworking
  • I protocolli TCP/IP

Parte 2: (20 ore)

  • La programmazione ad oggetti
  • Il linguaggio a oggetti Java
  • Le classi Java: definizioni, uso, package
  • Ereditarieta' in Java, classi derivate, classi astratte e interfacce1
  • Le eccezioni in Java
  • Input Output in Java

Parte 3: (25 ore)

  • Il concetto di socket
  • Programmazione socket TCP e UDP in Java
  • Realizzazione protocolli applicativi in Java
  • La programmazione RMI in Java
  • Gestione della Sicurezza
  • Crittografia
