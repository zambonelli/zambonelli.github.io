L'Ambiente di Sviluppo Java

Per eseguire i programmi Java bisogna scaricare e installare il Java Standard Development Kit, versione 1.4.x o superiori (denominato semplicemente Java 2 SDK).Esso si puo' trovare su vari siti semplicemente cercando su Google Java 2 SDK. In ogni caso, il sito ufficiale e' quello della Sun: Download Java.

Java SDK si installa automaticamente.

L'ambiente di sviluppo Jcreator

Poiche' Java 2 SDK e' un ambiente a "comandi", e' sicuramente utile avere a disposizione un ambiente di programmazione integrato. Il migliore di pubblico dominio e' sicuramente Jcreator, che puo' essere scaricato dal sito JCREATOR. Si consiglia di scaricare una della versione "LE" (Light Edition) che non hanno scadenza. L'installazione e' semplice e richiede solo di specificare la cartella di installazione di Java.

IMPORTANTE: JCreator funziona solo se e' stato precedentemente installato Java 2 SDK.
