Si indicano di seguito gli strumenti software che si utilizzano durante i moduli C e D e si indica dove e' possibile reperirli.


Programmazione in C

  • Si utilizza l'ambiente di programmazione integrato Turbo C della Borland, che comprende anche il compilatore Assembler. Il sistema non e' di pubblico domino. Percio', anche se e' potenzialmente molto facile copiare tale sistema per installarlo sul proprio PC a casa, il docente scoraggia l'adozione di questa pratica.
  • E'possibile, per la parte C, usare un ambiente di programmazione integrato per il C disponibile qui: Il compilatore DJGPP



Programmazione CGI

Per la programmazione CGI (o meglio, per testare i programmi realizzati come CGI) e' necessario installare sul PC un Web Server abilitato alla gestione delle CGI.

CONSIGLIATO Analog Web Server, di semplicissima installazione. Potete scaricare il software QUI

Per chi dispone di Win95 o Successivi sul Proprio PC, e' anche disponibile il Web Server di pubblico dominio APACHE, che e' disponibile per il download QUI . Attenzione: per usarlo su Win95 bisogna aggiornare il software di rete. Non ha invece problemi su Win98, ME, 2000, e NT.
