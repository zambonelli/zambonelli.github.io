FINALITÁ DEI MODULI E CONSIGLI UTILI

Scopo dei moduli e' approfondire i concetti di base della programmazione e della gestione di strutture dati, fino ad arrivare ad una piena padronanza nella progettazione e nello sviluppo di progetti software di una certa complessita'. In continuita' con i moduli precedenti, si adottera' il C come linguaggio di programmazione di riferimento.

MODULO C

Il modulo C si sviluppera' sui seguenti argomenti:

  • Dati Strutturati in C: Record e Puntatori
  • Gestione di Liste Dinamiche in C
  • Gestione di Alberi in C
  • Studio della Complessita'
  • Progetto multi-modulo dei programmi
  • Dalla programmazione modulare alla programmazione ad oggetti

Per superare agevolmente l'esame si consiglia agli studenti di seguire con continuitá le lezioni e le esercitazioni del corso. Inoltre, si consiglia di non focalizzare la preparazione dell'esame sullo studio dei libri e degli appunti, ma piuttosto di preparare l'esame sperimentando direttamente i concetti presentati a lezione sul calcolatore. Puó risultare estremamente difficile superare con successo l'esame senza una conoscenza di tipo sperimentale, ottenuta con esercitazioni in laboratorio.

Ambienti di Programmazione Utilizzati: Borland C, accessibile dai computer del laboratorio. E' possibile utilizzare in alternativa l'ambiente di programmazione DJGPP, di pubblico dominio, che risulta in quanto a interfaccia di uso e funzionalita' assolutamente equivalente al Borlandc. Per scaricare ed installare DJGPP CLIKKA QUI

MODULO D

Per quanto riguarda il modulo D, lo scopo e' quello di realizzare un progetto software (su tema a scelta dello studente o, in mancanza di fantasia, su temi proposti dal docente) di una certa complessita' in linguaggio C e fruibile attraverso il Web. In particolare, il progetto dovra' presentare le seguenti caratteristiche:

  • Essere opportunamente realizzato attraverso uso di librerie, con la relativa scomposizione del codice sorgente in moduli e file header.
  • Essere fruibile con interfaccia grafica HTML: il programma deve prendere l'input da form HTML; il programma stesso deve essere realizzato compatibilmente alla interfaccia CGI; il programma deve generare output in formato HTML.
  • L'output HTML del programma deve contenere immagini, sia presistenti che generate dinamicamente dal programma stesso (le immagini generate dal programma dovranno essere in formato bmp, e poi essere convertite in gif o jpg attraverso funzioni di libreria che verranno fornite all'interno del corso stesso).
  • Il programma deve fare uso del file system per memorizzare e recuperare informazione memorizzata in forma persistente.



STRUMENTI UTILIZZATI: Compilatore C, Web server di pubblico dominio, alcune funzioni di libreria per la generazione di immagini gif e jpg a partire da file bitmap.
